What should we build?

Open one of your GitHub repositories or create a new project, then describe the change you want. The agent reads and edits the code, runs commands, and pushes when you ask.

Enter to send, Shift + Enter for a new line

Push to GitHub

Commit every change and push it to GitHub. If the repository deploys through GitHub Actions, the deploy is followed and the public URL appears in the conversation when it is live.

Clear chat

Forget this conversation on the server, including the agent's memory of it, on every device. The code in the repository is not touched.

Reset repository

Delete every file in the checkout except the GitHub workflow in .github/workflows, and clear the conversation. Nothing is pushed until you push; the next push replaces the old app on GitHub.
